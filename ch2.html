2.1 Regular Expressions (RE)
Definition

A Regular Expression is a formal notation for describing a Regular Language. The language accepted by a Finite Automaton can always be described by a Regular Expression, and vice versa — they are equivalent in power.

2.1.1 Formal Definition (Recursive)

Let Σ be an alphabet. The set of Regular Expressions over Σ is defined as:

Basis/Rule RE Denotes Regular Set
Basis 1 φ Empty set { } — empty language
Basis 2 ε Null/empty string {ε}
Basis 3 a where a∈Σ Single symbol {a}
Inductive 1 R₁ + R₂ Union (OR) L(R₁) ∪ L(R₂)
Inductive 2 R₁ · R₂ Concatenation L(R₁) · L(R₂)
Inductive 3 R* Kleene closure Zero or more of R
Inductive 4 R⁺ Positive closure One or more of R
Operator Precedence (High to Low)
  • 1st (highest): Kleene star * and positive closure ⁺
  • 2nd: Concatenation (implicit dot ·)
  • 3rd (lowest): Union +
  • Parentheses () override all precedence rules
Basic RE Examples — L(r)

r = a + b → L(r) = {a, b}

r = a.b → L(r) = {ab}

r = a* → L(r) = {ε, a, aa, aaa, aaaa, ...}

r = a⁺ → L(r) = {a, aa, aaa, aaaa, ...} (no ε)

r = (a+b)* → L(r) = all strings over {a,b} including ε

2.1.2 Regular Expression Identities (Laws)

Used to simplify and manipulate Regular Expressions:

# Identity Explanation
1 φ + R = R Union with empty set changes nothing
2 φR = Rφ = φ Concatenation with empty set = empty set
3 εR = Rε = R ε is the identity for concatenation
4 ε* = ε   and   φ* = ε Kleene star of ε or φ gives {ε}
5 R + R = R Idempotent law — union with itself
6 R*R* = R* Multiple stars collapse into one
7 RR* = R*R = R⁺ Both mean "one or more R"
8 (R*)* = R* Star is idempotent
9 ε + RR* = R* = ε + R*R Adding ε to R⁺ gives R*
10 (PQ)*P = P(QP)* Shifting property
11 (P+Q)* = (P*Q*)* = (P*+Q*)* Union and closure equivalences
12 (P+Q)R = PR + QR Left distributive law
13 R(P+Q) = RP + RQ Right distributive law

Grammar from RE — Standard Template
  • RE = (a+b)*abb → Grammar: S → Aabb, A → aA | bA | ε
  • RE = abb(a+b)* → Grammar: S → abbA, A → aA | bA | ε
  • Pattern: The fixed part becomes part of S; the variable part becomes a non-terminal with self-loops.
2.2.3 Interpreting RE in English
Regular Expression English Description
a*b* Any number of a's followed by any number of b's. The string "ba" can NEVER appear in these strings — all a's come before all b's.
b*ab* All strings containing EXACTLY one 'a'. Any b's before and after the single 'a'.
(11+0)*(00+1)* Strings formed by concatenating repetitions of "11" or "0", followed by repetitions of "00" or "1".
(1+01+001)*(ε+0+00) Strings from {1,01,001} repeated, then optionally followed by at most two 0s. These strings never have more than two consecutive 0's.
[00+11+(01+10)(00+11)*(01+10)]* All binary strings containing an EVEN number of 0's AND an EVEN number of 1's.
2.3 DFA — Deterministic Finite Automaton
Definition

A DFA is a 5-tuple M = (Q, Σ, δ, q₀, F) where for every state and every input symbol, there is exactly ONE transition to a next state. No ambiguity, no ε-transitions.

5-Tuple Components
  • Q — Finite set of states
  • Σ — Input alphabet
  • δ: Q×Σ→Q — Transition function
  • q₀ ∈ Q — Start state
  • F ⊆ Q — Accept states
DFA Diagram Conventions
  • States = circles
  • Start state = arrow pointing to it
  • Accept state = double circle
  • Transitions = labeled arrows
  • Dead/trap state = non-accepting sink state

2.4 NFA & ε-NFA
NFA Definition

A Non-deterministic Finite Automaton (NFA) is a 5-tuple (Q, Σ, δ, q₀, F) where the transition function is δ: Q × Σ → P(Q) (maps to a SUBSET of states — zero, one, or more). An NFA accepts a string if ANY computation path leads to an accept state.

DFA vs NFA — Key Differences
  • DFA: δ: Q×Σ → Q (one next state)
  • NFA: δ: Q×Σ → P(Q) (set of states)
  • NFA allows 0, 1, or more transitions per symbol
  • NFA allows ε-transitions (ε-NFA)
  • Both accept exactly Regular Languages
  • Every DFA is a special case of NFA
NFA Acceptance Rule
  • NFA accepts w if at least one computation path ends in an accept state
  • NFA rejects w if ALL paths reject or get stuck
  • Think of NFA as trying all paths simultaneously
  • NFA is easier to design; DFA is easier to implement

2.5 NFA → DFA Conversion (Subset Construction)
Algorithm — Subset Construction

Each state in the resulting DFA corresponds to a subset of NFA states. The DFA state is a final state if any NFA state in the subset is a final state.

Step-by-Step Algorithm
  • Step 1: Compute ε-closure of NFA start state → this is the DFA start state.
  • Step 2: For each DFA state (subset) S and each input symbol a, compute: ε-closure(δ(S, a)) = set of all states reachable from any state in S on input a, then following ε-moves.
  • Step 3: If a new subset is generated, add it as a new DFA state.
  • Step 4: Mark any DFA state containing an NFA final state as a DFA final state.
  • Step 5: Repeat until no new states appear. Worst case: 2ⁿ states for n-state NFA.
Solved Example — NFA to DFA Conversion

NFA: Q = {q0, q1, q2}, Σ = {a, b}, start = q0, final = {q2}

Transitions: δ(q0,a) = {q0,q1}, δ(q0,b) = {q0}, δ(q1,b) = {q2}, δ(q2,a) = {q2}, δ(q2,b) = {q2}

DFA State (Subset) Input: a Input: b Type
→ {q0} {q0,q1} {q0} Start
{q0,q1} {q0,q1} {q0,q2} —
{q0,q2} {q0,q1,q2} {q0,q2} Accept
{q0,q1,q2} {q0,q1,q2} {q0,q2} Accept

This NFA accepts strings over {a,b} ending in 'ab'. The DFA has 4 states (NFA had 3). A DFA state is final if any NFA state in the subset is final (here q2 is the NFA final state).

2.6 DFA → Regular Expression (Arden's Theorem)
Arden's Theorem

If P and Q are Regular Expressions and P does not contain ε, then the equation R = Q + RP has a unique solution: R = QP*

Used to solve simultaneous equations for each DFA state to find the overall RE.

Method — State Equations from DFA

For each state qᵢ, write an equation: qᵢ = (sum of: qⱼ·symbol for each transition from qⱼ to qᵢ)

For start state q0, also add ε.

Solve using Arden's theorem and substitution. Final answer = equation for start state (or union if multiple final states).

Solved Example — DFA to RE for strings ending in 'ab'

States: q0 (start), q1, q2 (accept). Transitions as in Fig 2.1.

State equations:

q0 = ε + q0·b + q2·b
q1 = q0·a + q1·a + q2·a
q2 = q1·b

Solve q1 using Arden's (q1 = q1·a is of form R = RP + Q):

q1 = (q0·a + q2·a)·a* = (q0 + q2)·a·a*

Substitute q2 = q1·b, then q1:

Final RE = (a+b)*ab
2.7 Closure Properties of Regular Languages
Definition

Closure Properties tell us: if we perform a certain operation on Regular Languages, is the resulting language still Regular? The answer for Regular Languages is YES for all the operations listed below.

Operation Closed? Proof Method
Union — L₁ ∪ L₂ ✓ YES RE: R₁+R₂ is also a RE. DFA: Product construction (final = final in DFA₁ OR DFA₂)
Concatenation — L₁·L₂ ✓ YES RE: R₁·R₂ is a RE. NFA: connect final states of NFA₁ to start of NFA₂ with ε-transitions
Kleene Star — L* ✓ YES RE: R* is a RE. NFA: add ε back-loops and new start/final states
Complement — L̄ ✓ YES DFA: swap all final and non-final states. Requires COMPLETE DFA.
Intersection — L₁ ∩ L₂ ✓ YES Product construction: final = final in DFA₁ AND DFA₂. Or: L₁∩L₂ = (L̄₁ ∪ L̄₂)̄
Difference — L₁ − L₂ ✓ YES L₁ − L₂ = L₁ ∩ L̄₂. Closed since closed under ∩ and complement.
Reversal — Lᴿ ✓ YES Reverse all DFA arrows; swap start/final states → get NFA for Lᴿ.
Homomorphism ✓ YES Apply homomorphism h to each RE symbol → still regular.
2.7.1 Closure Under Complement — Proof in Detail
Theorem

If L is a Regular Language over Σ, then L̄ = Σ* − L is also Regular.

Proof (DFA Construction)
  • Step 1: Take the complete DFA M for L (every state must have transitions on every symbol — add dead state if needed).
  • Step 2: Create new DFA M' with same states and transitions.
  • Step 3: Exchange final and non-final states: F' = Q − F.
  • Result: M' accepts exactly those strings that M rejects → L(M') = L̄.
  • ⚠ Critical: The DFA MUST be complete before swapping. Incomplete DFA leads to wrong complement.
2.7.2 Closure Under Intersection — Product Construction
Product Construction for DFA₁ × DFA₂

DFA states: Q = Q₁ × Q₂ (all pairs)

Start state: (q₀₁, q₀₂)

Transitions: δ((p,q), a) = (δ₁(p,a), δ₂(q,a))

For Union (∪): Final states = {(p,q) | p ∈ F₁ OR q ∈ F₂}

For Intersection (∩): Final states = {(p,q) | p ∈ F₁ AND q ∈ F₂}

Important — NOT Closed Under

Regular Languages are NOT closed under infinite union or infinite intersection. Only finite union and finite intersection are guaranteed to stay regular.

2.8 Pumping Lemma for Regular Languages
Purpose

The Pumping Lemma is a necessary condition for Regular Languages. It is used to prove that a language is NOT Regular (via contradiction). It CANNOT be used to prove a language IS regular.

2.8.1 Statement of Pumping Lemma
Pumping Lemma — Formal Statement
  • If L is a Regular Language, then there exists a constant n (pumping length) such that:
  • For every string w ∈ L with |w| ≥ n, we can write w = xyz where:
  • Condition 1: |y| > 0 — y is non-empty (the "pump" part)
  • Condition 2: |xy| ≤ n — x and y together are at most length n
  • Condition 3: ∀ i ≥ 0: xyⁱz ∈ L — pumping y any number of times stays in L
w = xyz where |y| > 0, |xy| ≤ n, ∀i≥0: xyⁱz ∈ L

Note: xy⁰z = xz, xy¹z = xyz = w, xy²z = xyyz, etc.

2.8.2 Proof Strategy (Contradiction)
Steps to Prove L is NOT Regular
  • Step 1: Assume L is Regular (for contradiction).
  • Step 2: Let n be the pumping length guaranteed by the Pumping Lemma.
  • Step 3: Choose a specific string w ∈ L with |w| ≥ n (choose wisely — usually the "hardest" case).
  • Step 4: Consider ALL possible ways to split w = xyz satisfying conditions 1 and 2.
  • Step 5: For each split, find some i ≥ 0 such that xyⁱz ∉ L (usually i=0 or i=2 works).
  • Step 6: This contradicts condition 3 → L is NOT Regular. □
2.8.3 Classic Example 1 — L = {aⁿbⁿ | n ≥ 0}
Prove: L = {aⁿbⁿ | n ≥ 0} is NOT Regular

Step 1: Assume L is Regular with pumping length n.

Step 2: Choose w = aⁿbⁿ ∈ L (|w| = 2n ≥ n ✓).

Step 3: By condition 2: |xy| ≤ n → xy consists entirely of a's → y = aᵏ (k > 0).

Step 4: Pump with i = 0: xy⁰z = xz = aⁿ⁻ᵏbⁿ. Since k > 0, number of a's < number of b's.

Step 5: xz ∉ L → Contradiction. Therefore L is NOT Regular. □

Pumping Lemma visualization for w = aⁿbⁿ — y is always in the 'a' section
2.8.4 Classic Example 2 — L = {aᵖ | p is prime}
Prove: L = {aᵖ | p is prime} is NOT Regular

Step 1: Assume L is Regular with pumping length n.

Step 2: Choose w = aᵖ where p ≥ n+2 is prime. So |w| = p ≥ n ✓.

Step 3: w = xyz, |y| = k > 0, |x| = j. So w = aʲ·aᵏ·aᵖ⁻ʲ⁻ᵏ.

Step 4: Pump with i = p: xyᵖz has length j + pk + (p-j-k) = p + pk - k = p(1+k) - k.

Step 5: For xyᵖz ∈ L, |xyᵖz| = p + (p-1)k must be prime. But p + (p-1)k = p(1 + k) − k. When we choose i such that |xyⁱz| is composite → contradiction.

Alternatively: pump i=0, |xz| = p-k. We need p-k to be prime, but for k dividing p-something, this fails for some choice. Therefore L is NOT Regular. □

Common Mistake

The Pumping Lemma says: if L is regular THEN every long string can be pumped. The CONTRAPOSITIVE is: if some long string CANNOT be pumped, THEN L is not regular. You CANNOT use Pumping Lemma to prove a language IS regular.

2.9 Moore & Mealy Machines (FA with Output)
Overview

Moore and Mealy machines are Finite State Machines with output. Unlike DFA/NFA (which only accept or reject), these machines produce an output string for every input string.

2.9.1 Moore Machine
Definition

A Moore Machine is a 6-tuple (Q, Σ, Δ, δ, λ, q₀) where the output λ: Q → Δ depends only on the CURRENT STATE.

Moore 6-Tuple
  • Q — Finite set of states
  • Σ — Input alphabet
  • Δ — Output alphabet
  • δ: Q×Σ → Q — Transition function
  • λ: Q → Δ — Output function (STATE only)
  • q₀ — Initial state
Moore Key Properties
  • Output written inside the state circle
  • For n input symbols → n+1 outputs (initial state produces first output)
  • Output is produced when entering a state
  • Same state always gives same output regardless of input
Figure 2.7 — Moore Machine detecting substring 'ab'. Output = 1 when 'ab' just completed, else 0. Note: output is written inside the circle (associated with state).
2.9.2 Mealy Machine
Definition

A Mealy Machine is a 6-tuple (Q, Σ, Δ, δ, λ, q₀) where the output λ: Q×Σ → Δ depends on BOTH the current state AND the current input symbol.

Mealy 6-Tuple
  • Q — Finite set of states
  • Σ — Input alphabet
  • Δ — Output alphabet
  • δ: Q×Σ → Q — Transition function
  • λ: Q×Σ → Δ — Output function (STATE + INPUT)
  • q₀ — Initial state
Mealy Key Properties
  • Output written on the transition arrow (input/output)
  • For n input symbols → n outputs (no initial output)
  • Output produced during transition
  • Two transitions from same state can give different outputs
Figure 2.8 — Mealy Machine for 2's complement of binary input (read LSB first). Scan right-to-left: copy 0s until first 1, copy 1, then flip all subsequent bits.
Mealy Trace — 2's complement of "1010" (read LSB=rightmost first)

Input: 0 → 1 → 0 → 1 (LSB to MSB: 0, 1, 0, 1)

q0 on 0: stay q0, output 0

q0 on 1: go q1, output 1

q1 on 0: stay q1, output 1

q1 on 1: stay q1, output 0

Output: 0110 → 2's complement of 1010 (=10 decimal) is 0110 (=6... wait: 2's comp of -6 in 4-bit is 1010, complement is 0110 ✓)

2.9.3 Moore vs Mealy — Comparison
Feature Moore Machine Mealy Machine
Output depends on State only State AND Input
Output location in diagram Inside the state circle On the transition arrow (input/output)
Output function λ: Q → Δ λ: Q × Σ → Δ
Outputs for n inputs n + 1 outputs n outputs
Initial output Yes (from start state) No initial output
State count Usually MORE states Usually FEWER states
Response time Output after state change (slower) Output during transition (faster)
Equivalent? YES — Every Moore machine has an equivalent Mealy machine and vice versa
2.9.4 Conversion — Mealy to Moore
Mealy → Moore Conversion Algorithm
  • Problem: In Mealy, a single state can have transitions with DIFFERENT outputs. In Moore, each state has ONE fixed output.
  • Solution: Split states that have transitions with different outputs into separate states, one per distinct output.
  • Step 1: For each state qᵢ in Mealy, check the output on all incoming transitions.
  • Step 2: If all incoming transitions to qᵢ have the same output x → assign output x to qᵢ.
  • Step 3: If qᵢ has incoming transitions with different outputs → split qᵢ into qᵢ/x₁, qᵢ/x₂, ... one per distinct output.
  • Step 4: Redirect each incoming transition to the appropriate split state.
  • Start state: Assign arbitrary output (or create a new start state if needed).
2.9.5 Conversion — Moore to Mealy
Moore → Mealy Conversion Algorithm
  • This is simpler — Moore to Mealy never increases states.
  • Step 1: Copy all states and transitions from the Moore machine.
  • Step 2: For each transition δ(qᵢ, a) = qⱼ in Moore, the Mealy output is λ_Mealy(qᵢ, a) = λ_Moore(qⱼ) (output of the TARGET state in Moore).
  • Step 3: The initial output of the Moore machine (output at q₀ before any input) is dropped in Mealy — this is the only difference.
  • Result: Same number of states. Mealy and Moore machines are equivalent in language power.

8

Prove: L = {ww | w ∈ {a,b}*} is NOT Regular using Pumping Lemma.

Choose: w = aⁿbaⁿb ∈ L (this is ss where s = aⁿb).

Therefore L is NOT Regular. □

YES, L is Regular. RE = (ab)*

q0 on 0 → q0/0 | on 1 → q1/0
q1 on 0 → q0/0 | on 1 → q1/1
Meaning: Output 1 only on consecutive 1s. RE for strings triggering output 1: (0+10)*11(0+10)*
11

Convert the Moore Machine (q0:A, q1:B) with δ(q0,0)=q1, δ(q0,1)=q0, δ(q1,0)=q0, δ(q1,1)=q1 to Mealy Machine.

Rule: Mealy output on transition = Moore output of TARGET state.
q0 on 0 → q1, output = B
q0 on 1 → q0, output = A
q1 on 0 → q0, output = A
q1 on 1 → q1, output = B
Note: Initial Moore output (A at q0 before any input) is lost in Mealy.
12

Design a Moore Machine over {a,b} that outputs 1 if input ends with 'aba', else outputs 0.

States track the suffix seen so far:
q0: output 0 (no match prefix)
q1: output 0 (saw 'a')
q2: output 0 (saw 'ab')
q3: output 1 (saw 'aba' ← accept!)
Transitions: q0→a→q1, q0→b→q0, q1→b→q2, q1→a→q1, q2→a→q3, q2→b→q0, q3→a→q1, q3→b→q2
2.11 Quick Revision — Chapter 2
Concept Key Fact
Regular Expression Formal notation for Regular Languages. Basis: φ, ε, a. Operations: +, ·, *, ⁺.
RE Precedence * and ⁺ > concatenation > union (+). Use () to override.
Even length RE ((a+b)(a+b))* — pair up symbols.
DFA 5-tuple (Q,Σ,δ,q₀,F). Exactly ONE transition per (state,symbol). δ:Q×Σ→Q.
NFA 5-tuple same, but δ:Q×Σ→P(Q). Zero or more transitions. Easier to design.
ε-NFA NFA with ε-transitions. Same power as DFA and NFA.
DFA = NFA = ε-NFA = RE All equivalent — all describe exactly Regular Languages.
Thomson's Construction Converts RE → ε-NFA inductively (union, concatenation, star rules).
Subset Construction Converts NFA → DFA. DFA states are subsets of NFA states. Worst case: 2ⁿ states.
Arden's Theorem R = Q + RP → R = QP*. Used to convert DFA → RE.
Closure Properties Regular Languages closed under: ∪, ·, *, complement, ∩, difference, reversal.
Complement DFA Swap final and non-final states. Requires COMPLETE DFA first.
Pumping Lemma Tool to prove languages are NOT regular. w=xyz, |y|>0, |xy|≤n, xyⁱz∈L for all i≥0.
Moore Machine Output associated with STATE. λ:Q→Δ. n inputs → n+1 outputs.
Mealy Machine Output associated with TRANSITION. λ:Q×Σ→Δ. n inputs → n outputs.
Moore→Mealy Mealy output = Moore output of TARGET state. Lose initial output.
Mealy→Moore Split states with different incoming outputs. More states in Moore.
{aⁿbⁿ} NOT Regular (context free). Classic Pumping Lemma proof.
🎯 Exam Must-Remember
  • RE for even length = ((a+b)(a+b))*; odd length = ((a+b)(a+b))*(a+b)
  • RE for "exactly twice 'a'" = b*ab*ab*; "at least twice" = b*ab*a(a+b)*
  • DFA complement: swap final ↔ non-final. Must have COMPLETE DFA first.
  • NFA→DFA: each DFA state = SUBSET of NFA states. Final DFA state = subset containing NFA final state.
  • Moore: output inside state. Mealy: output on transition (input/output label).
  • Moore→Mealy: output of Mealy transition = output of Moore's TARGET state.
  • Pumping Lemma proves NOT regular. Cannot prove IS regular.
  • Arden's: R = Q + RP → R = QP* (P must not contain ε).
  • Product construction: union = OR of finals; intersection = AND of finals.
  • RE identity: ε + RR* = R* and (R*)* = R*
