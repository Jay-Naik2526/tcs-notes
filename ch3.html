3.1 Introduction — FA With Output

Finite Automata are broadly classified based on whether they produce output:

🔵 Without Output
  • DFA — Deterministic FA
  • NFA — Non-deterministic FA
  • ε-NFA — Epsilon NFA
  • Only produce: Accept / Reject
  • Final state determines result
🟣 With Output
  • Moore Machine — output per state
  • Mealy Machine — output per transition
  • Produce a string of output symbols
  • Used in: digital circuits, coding systems, pattern recognition
Why Machines with Output?
  • In many practical systems, we need more than just "yes/no" — we need to produce a response.
  • Examples: sequence detectors, binary arithmetic circuits, data encoders, protocol handlers.
  • Moore and Mealy machines are equivalent in power — every Moore machine has an equivalent Mealy machine and vice versa.
3.2 Moore Machine
3.2.1 Definition & 6-Tuple
Definition

A Moore Machine is a Finite State Machine where the OUTPUT is associated with the STATE. The output depends ONLY on the current state — not on the input symbol.

M = (Q, Σ, Δ, δ, λ, q₀)
Symbol Name Description
Q States Finite, non-empty set of states
Σ Input Alphabet Finite set of input symbols
Δ Output Alphabet Finite set of output symbols
δ: Q×Σ → Q Transition Function Maps (state, input) → next state
λ: Q → Δ Output Function Maps state → output symbol (STATE ONLY)
q₀ Initial State Starting state (q₀ ∈ Q)
Moore Machine — Key Rules
  • Output is written inside the state (labeled as "state/output" or two lines).
  • For an input of length n → produces n+1 outputs (initial state + one per transition).
  • Same state always gives the same output regardless of input.
  • Transition arrows are labeled with input only (no output on arrows).
3.2.2 Diagram Conventions
Moore: output inside state circle (state/output) | Mealy: output on transition arrow (input/output)
3.2.3 Problem 1 — Moore Machine: Count Occurrences of "ab"
Problem Statement

Construct a Moore Machine over Σ = {a, b} that counts the number of times the substring "ab" appears in the input. The output at any point should reflect the count of "ab" seen so far.

Design Insight: We track whether we are in a position to complete "ab". Three states are needed:

State Output Meaning
q0 0 Initial — no 'a' recently seen that could start "ab"
q1 0 Just read an 'a' — waiting for 'b' to complete "ab"
q2 1 Just completed reading "ab" — output shows one occurrence
Current State / Output Input 'a' → Next Input 'b' → Next
→ q0 / 0 q1 q0
q1 / 0 q1 q2
q2 / 1 q1 q0
Figure 3.1 — Moore Machine for counting "ab" occurrences. Output 1 at q2 = one "ab" found.
Trace — Input "abab"
Step Input Current State Output Next State
Start — q0 0 —
1 a q0 0 q1
2 b q1 0 q2
3 a q2 1 q1
4 b q1 0 q2
End — q2 1 —

Output sequence: 0, 0, 1, 0, 1 — The 1s appear when "ab" has been detected (at positions 3 and 5). Total 2 occurrences of "ab" in "abab".

3.2.4 Problem 2 — Moore Machine: Suffix Detection ("101" or "110")
Problem Statement

Construct a Moore Machine over Σ = {0,1} that produces 'A' if input ends with "101", 'B' if input ends with "110", and 'C' otherwise.

Design Insight: States must track the last 2 meaningful symbols to detect 3-symbol patterns.

State Output Suffix Tracked
q0 C Initial / no useful suffix
q1 C Last symbol was '1'
q2 C Last two were "10"
q3 C Last two were "11"
q4 A Last three were "101" ← DETECTED
q5 B Last three were "110" ← DETECTED
State / Output Input 0 → Next Input 1 → Next
→ q0 / C q0 q1
q1 / C q2 q3
q2 / C q0 q4
q3 / C q5 q3
q4 / A q2 q1
q5 / B q0 q1
Figure 3.2 — Moore Machine for suffix detection. q4 outputs 'A' (101 detected), q5 outputs 'B' (110 detected), all others output 'C'.
3.2.5 Problem 3 — Moore Machine: 1's Complement
Problem Statement

Construct a Moore Machine to find the 1's complement of a binary number. Input: binary string. Output: each bit flipped (0→1, 1→0).

Design Insight: The output of the current state should be the complement of the input that caused us to ENTER that state. Two states — one representing "last input was 0" (output 1) and one representing "last input was 1" (output 0).

State / Output Meaning Input 0 → Next Input 1 → Next
→ q0 / 0 Start / last seen 1 q1 q0
q1 / 1 Last seen 0 → output 1 q1 q0
Figure 3.3 — Moore Machine for 1's complement. State output = complement of input that entered this state.
Trace — Input "101" → Expected Output "010"
Step Input Current State Output Next State
Start — q0 0 (ignored) —
1 1 q0 — q0
2 0 q0 — q1
3 1 q1 — q0
End — q0 — —

Output sequence after 1st symbol: when entering q0 (output 0), when entering q1 (output 1), entering q0 (output 0) → 0, 1, 0 = complement of "1, 0, 1" ✓

Note: Moore produces n+1 outputs. The first output (start state) is typically discarded. The meaningful outputs are from transitions 1 through n.

3.2.6 Problem 4 — Moore Machine: Remainder when Divided by 3
Problem Statement

Construct a Moore Machine over Σ = {0,1} that reads a binary number and outputs the remainder when the number read so far is divided by 3. Output ∈ {0, 1, 2}.

Key Formula: If current value = n and we read bit b: new_value = 2n + b, so new_rem = (2×old_rem + b) mod 3

State / Output Remainder So Far Input 0 → Next Input 1 → Next
→ q0 / 0 rem = 0 q0 q1
q1 / 1 rem = 1 q2 q0
q2 / 2 rem = 2 q1 q2
Figure 3.4 — Moore Machine: remainder of binary number divided by 3. Formula: new_rem = (2×old_rem + bit) mod 3.
Trace — Input "110" = 6 decimal, 6 mod 3 = 0

Start: q0 (output 0) → read 1: q0→q1 → read 1: q1→q0 → read 0: q0→q0

Final state: q0 → output = 0 ✓ (6 mod 3 = 0)

Also: "111" = 7, 7 mod 3 = 1 → Trace: q0→q1→q0→q1, final output = 1 ✓

3.3 Mealy Machine
3.3.1 Definition & 6-Tuple
Definition

A Mealy Machine is a Finite State Machine where the OUTPUT is associated with the TRANSITION. The output depends on BOTH the current state AND the current input symbol.

M = (Q, Σ, Δ, δ, λ, q₀)
Symbol Name Description
Q States Finite, non-empty set of states
Σ Input Alphabet Finite set of input symbols
Δ Output Alphabet Finite set of output symbols
δ: Q×Σ → Q Transition Function Maps (state, input) → next state
λ: Q×Σ → Δ Output Function Maps (state, input) → output (BOTH state AND input)
q₀ Initial State Starting state
Mealy Machine — Key Rules
  • Output is written on the transition arrow as "input/output".
  • For an input of length n → produces exactly n outputs (no initial output).
  • Different transitions from the same state CAN give different outputs.
  • State circles are labeled with state name only (no output inside).
3.3.2 Problem 5 — Mealy Machine: Suffix Detection ("101" or "110")
Problem Statement

Design a Mealy Machine over Σ = {0,1} that produces 'A' when "101" is detected as a suffix, 'B' when "110" is detected, and 'C' otherwise.

Key Difference from Moore: In Mealy, the output is produced ON the transition that COMPLETES the pattern — not at the state. This means we need fewer states (no need for separate q4, q5 accept states).

State Meaning
q0 Initial / no useful suffix seen
q1 Last symbol was '1'
q2 Last two were "10"
q3 Last two were "11"
State Input 0 → Next / Output Input 1 → Next / Output
→ q0 q0 / C q1 / C
q1 q2 / C q3 / C
q2 q0 / C q1 / A ← "101" done!
q3 q2 / B ← "110" done! q3 / C
Figure 3.5 — Mealy Machine for suffix detection. Output A on transition completing "101"; output B completing "110"; C otherwise. Only 4 states vs Moore's 6.
Trace — Input "1101" → Expected Output: C,C,B,A
Step Input Current State Output Next State
1 1 q0 C q1
2 1 q1 C q3
3 0 q3 B q2
4 1 q2 A q1

Output sequence: C, C, B, A ✓

3.3.3 Problem 6 — Mealy Machine: 2's Complement (LSB First)
Problem Statement

Design a Mealy Machine to compute the 2's complement of a binary number. Input is given LSB first (right to left).

2's Complement Algorithm (LSB First)
  • Scan from the rightmost bit (LSB).
  • Copy all trailing 0s as 0s.
  • Copy the first 1 as 1.
  • Flip all remaining bits to their left.
State Meaning Input 0 → Next / Output Input 1 → Next / Output
→ q0 Haven't seen first '1' yet q0 / 0 (copy 0) q1 / 1 (copy first 1)
q1 Already found first '1' — flip all q1 / 1 (flip: 0→1) q1 / 0 (flip: 1→0)
Figure 3.6 — Mealy Machine for 2's complement (LSB first). q0 = copy phase, q1 = flip phase.
Trace — "1010" decimal=10, 2's complement = "0110" decimal=6

Input LSB first: 0, 1, 0, 1

Step Input (LSB→MSB) State Output Next
1 0 q0 0 q0
2 1 q0 1 q1
3 0 q1 1 q1
4 1 q1 0 q1

Output (LSB first): 0, 1, 1, 0 → Reading MSB first: 0110 = 6 ✓

3.3.4 Problem 7 — Mealy Machine: Detect "1010" (Overlapping)
Problem Statement

Design a Mealy Machine that outputs 1 whenever the sequence "1010" is detected as a suffix of the input read so far, with overlapping allowed. Otherwise output 0.

State Suffix Tracked 0 → Next/Out 1 → Next/Out
→ q0 Empty / no prefix q0 / 0 q1 / 0
q1 Seen "1" q2 / 0 q1 / 0
q2 Seen "10" q0 / 0 q3 / 0
q3 Seen "101" q2 / 1 q1 / 0

Note: When q3 receives '0', we go to q2 and output 1 (because "1010" was just completed). We move to q2 (not q0) because "10" is now the suffix — allowing overlapping detection.

Figure 3.7 — Mealy Machine detecting "1010" with overlapping. Output 1 only on the q3→q2 transition (★). After detection, move to q2 (not q0) to allow overlap.
3.4 Moore vs Mealy — Detailed Comparison
Feature Moore Machine Mealy Machine
Output depends on State ONLY — λ: Q → Δ State AND Input — λ: Q×Σ → Δ
Output location Inside state circle On transition arrow (input/output)
Output for n inputs n + 1 outputs n outputs (no initial)
Initial output YES — from start state before any input NO — first output on first input
State count Generally MORE states Generally FEWER states
Response time Slower — output after state change Faster — output during transition
Glitch-prone? Less prone (output stable per state) More prone (output changes mid-clock)
Synchronization Synchronized with states (clocked) Synchronized with transitions
Design complexity Higher — more states for same task Lower — fewer states needed
Equivalent? YES — Both recognize the same class of languages and can be converted to each other
State Count Comparison — "Ends with 01" over {0,1}

Moore Machine: Needs 4 states — q0 (C), q1 (C: saw '0'), q2 (A: saw '01'), q3 (C: saw '1') — because each output must be tied to a state.

Mealy Machine: Needs only 3 states — q0 (start), q1 (saw '0'), q2 (saw '1'). Output 1 is produced ON the transition q1→q2 when '1' is read after '0'. No extra accept state needed.

This is the general pattern: Mealy states ≈ Moore states − 1 (when Moore has dedicated accept states).

3.5 Conversion: Moore → Mealy
Algorithm — Moore to Mealy
  • Rule: Mealy output on a transition = Moore output of the TARGET state.
  • Step 1: Copy all states from Moore to Mealy (keep same structure).
  • Step 2: For each transition δ(q, a) = q' in Moore:
    In Mealy: δ(q, a) = q' with output = λ_Moore(q')
  • Step 3: Remove the initial output (output at start state before any input — Mealy has no initial output).
  • Result: Same number of states. Simpler arrows. No output lost except the initial one.
Solved Example — Moore to Mealy Conversion

Given Moore Machine:

State Output (λ) On 'a' → Next On 'b' → Next
→ q0 0 q1 q0
q1 1 q1 q0

Conversion Steps:

1
For transition q0 →a→ q1: Mealy output = λ_Moore(q1) = 1
2
For transition q0 →b→ q0: Mealy output = λ_Moore(q0) = 0
3
For transition q1 →a→ q1: Mealy output = λ_Moore(q1) = 1
4
For transition q1 →b→ q0: Mealy output = λ_Moore(q0) = 0

Resulting Mealy Machine:

State On 'a' → Next / Output On 'b' → Next / Output
→ q0 q1 / 1 q0 / 0
q1 q1 / 1 q0 / 0
Figure 3.8 — Moore to Mealy conversion. Mealy output on each arrow = output of Moore's TARGET state. Note: output labels move from inside states to on arrows.
3.6 Conversion: Mealy → Moore
Algorithm — Mealy to Moore (State Splitting)
  • Problem: In Moore, each state has ONE fixed output. In Mealy, a state can be reached by transitions with DIFFERENT outputs. So we must split such states.
  • Step 1: For each Mealy state q, find all distinct outputs on incoming transitions.
  • Step 2: If all incoming transitions have the same output x → Keep q as one Moore state with output x.
  • Step 3: If incoming transitions have different outputs → Split q into q/x₁, q/x₂, ... one per distinct incoming output.
  • Step 4: Rebuild all transitions: each transition from state p on input a that went to q now goes to the appropriate split of q.
  • Step 5: For the start state q₀ — since no transition leads into it, assign an arbitrary output (typically 0 or the most common output).
Solved Example — Mealy to Moore Conversion

Given Mealy Machine:

State On 'a' → Next / Output On 'b' → Next / Output
→ q0 q1 / 0 q1 / 1
q1 q0 / 0 q0 / 1

Step 1 — Analyze incoming transitions:

1
q0: Incoming from q1 on 'a' (output 0) and q1 on 'b' (output 1) → TWO different outputs → SPLIT q0 into q0/0 and q0/1
2
q1: Incoming from q0 on 'a' (output 0) and q0 on 'b' (output 1) → TWO different outputs → SPLIT q1 into q1/0 and q1/1
3
Start state q0: No incoming → assign output 0 arbitrarily → use q0/0 as start state

Step 2 — Build Moore transitions:

For each transition from original Mealy state q on input a with output x going to q': in Moore, transition from q/? on input a goes to q'/x.

Moore State / Output On 'a' → Next On 'b' → Next
→ q0/0 start q1/0 (Mealy: q0→q1/0) q1/1 (Mealy: q0→q1/1)
q0/1 q1/0 q1/1
q1/0 q0/0 (Mealy: q1→q0/0) q0/1 (Mealy: q1→q0/1)
q1/1 q0/0 q0/1
Observation

The resulting Moore Machine has 4 states where the Mealy had only 2. This is the general pattern — Mealy → Moore conversion usually increases the state count. However, the machines are behaviourally equivalent (they produce the same output for every input string, except for the extra initial output in Moore).

Figure 3.9 — Partial Moore Machine after Mealy→Moore conversion. 4 states vs original 2 Mealy states. q0/0 and q0/1 both represent Mealy's q0 but reached with different outputs.
3.7 Practice Questions
Design Questions
1

Design a Moore Machine over {a,b} that outputs 'Y' if the input string contains the substring "aba", and 'N' otherwise.

States: q0/N (start), q1/N (saw 'a'), q2/N (saw 'ab'), q3/Y (saw 'aba'!)
q0→a→q1, q0→b→q0; q1→b→q2, q1→a→q1; q2→a→q3, q2→b→q0; q3→a→q1, q3→b→q2
Once q3 is reached with 'Y', all future states retain the relevant tracking.
2

Design a Mealy Machine that detects whether two consecutive 1s appear in the input over {0,1}. Output 1 when "11" is first detected, then 0 for all subsequent inputs.

States: q0 (no 1 seen), q1 (one 1 seen), q2 (two 1s seen / locked).
q0: 0→q0/0, 1→q1/0. q1: 0→q0/0, 1→q2/1. q2: 0→q2/0, 1→q2/0.
3

Design both Moore and Mealy machines that recognize strings ending in "01" over {0,1}. Compare state counts.

Mealy (3 states): q0(start)→0→q1, q1→1→q2/1(output!), q2→0→q1, q1→0→q1, q0→1→q0, q2→1→q0.
Moore (4 states): q0/0(start), q1/0(saw 0), q2/1(saw 01, accept), q3/0(saw 1).
Moore needs 1 extra state to represent the accepting condition as an output-carrying state.
4

Construct a Moore Machine that outputs the number of 'a's seen mod 3 at each step, over Σ = {a,b}.

3 states tracking count mod 3:
q0/0 (0 a's mod 3), q1/1 (1 a mod 3), q2/2 (2 a's mod 3).
On 'a': q0→q1, q1→q2, q2→q0. On 'b': all self-loops (b doesn't affect count).
Conversion Questions
5

Convert the following Moore Machine to an equivalent Mealy Machine:

States: A/0, B/1, C/0. Start: A. δ(A,a)=B, δ(A,b)=C, δ(B,a)=A, δ(B,b)=C, δ(C,a)=B, δ(C,b)=A.

Rule: Mealy output = Moore output of TARGET state.
A: a→B/1, b→C/0. B: a→A/0, b→C/0. C: a→B/1, b→A/0.
Same 3 states. Initial Moore output (0 at A) is dropped.
6

Convert the following Mealy Machine to a Moore Machine:

States: P, Q. Start: P. P: a→Q/0, b→P/1. Q: a→P/0, b→Q/1.

Analyze incoming transitions:
P receives: Q→P on 'a' (output 0). Only output 0 → P → P/0 (no split).
Q receives: P→Q on 'a' (output 0). Only output 0 → Q → Q/0 (no split).
Wait — P also receives self-loop on 'b' (output 1). TWO outputs for P → split P into P/0 and P/1.
Similarly Q self-loop on 'b' (output 1) → Q splits into Q/0 and Q/1.
Result: 4 Moore states: P/0, P/1, Q/0, Q/1. Start = P/0.
7

Why is it that Moore → Mealy conversion never increases state count, but Mealy → Moore conversion usually does?

Moore → Mealy: Each Moore state already has ONE output. Moving the output from the state to the incoming transitions is a 1-to-1 relabeling. No states need to be split or merged.
Mealy → Moore: A single Mealy state can be reached by transitions with DIFFERENT outputs. In Moore, different outputs at the same state is impossible — so we must split the state into multiple Moore states, one per distinct incoming output. Hence state count increases.

For Mealy Machine detecting "1010" (Problem 7), trace input "10101". How many times is "1010" detected?

3.8 Quick Revision — Chapter 3
Concept Key Fact
Moore Machine Output depends on STATE only. λ: Q → Δ. Output inside state circle.
Mealy Machine Output depends on STATE + INPUT. λ: Q×Σ → Δ. Output on transition arrow (input/output).
Moore 6-Tuple (Q, Σ, Δ, δ, λ, q₀) — δ: Q×Σ→Q, λ: Q→Δ
Mealy 6-Tuple (Q, Σ, Δ, δ, λ, q₀) — δ: Q×Σ→Q, λ: Q×Σ→Δ
Output count Moore: n+1 (for n inputs). Mealy: n (for n inputs). Moore has extra initial output.
State count Moore usually has MORE states. Mealy usually has FEWER states.
Moore → Mealy Same states. Mealy output = Moore output of TARGET state. Drop initial Moore output.
Mealy → Moore Split states with different incoming outputs. Each split state gets one output value. State count increases.
Equivalent? YES — Moore and Mealy are equivalent in power and can recognize the same languages/produce same outputs.
Diagram: Moore State circle has two lines: state name on top, output on bottom. Arrows labeled with input only.
Diagram: Mealy State circle has only state name. Arrows labeled "input/output".
2's complement Mealy q0: copy phase (copy 0s and first 1). q1: flip phase (flip all remaining). Reads LSB first.
Suffix detection Moore Needs accept states (e.g., q4/A, q5/B) with the output. More states needed.
Suffix detection Mealy Output produced ON the completing transition. Fewer states — no dedicated output states.
Overlap detection After detecting "1010", go to q2 (not q0) to allow the "10" suffix to begin next "1010".
🎯 Exam Must-Remember
  • Moore: output INSIDE state. Mealy: output ON ARROW (input/output). Never mix them up.
  • Moore gives n+1 outputs; Mealy gives n outputs (for input length n).
  • Moore → Mealy: output of Mealy transition = output of Moore's TARGET state. Same state count.
  • Mealy → Moore: SPLIT states with multiple incoming output values. State count increases.
  • Start state in Mealy → Moore: assign arbitrary output (no incoming transition, so no splitting needed at start).
  • Both Moore and Mealy are Finite State Machines WITH output — they produce output strings, not just accept/reject.
  • They are equivalent in expressive power — any Moore machine can be converted to Mealy and vice versa.
  • In diagrams: DFA/NFA have double-circle for accept states. Moore/Mealy have no "accept states" — every state has an output.
