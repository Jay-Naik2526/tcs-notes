P1
L = {aⁿbⁿ | n ≥ 1}
Strings with equal a's followed by equal b's: ab, aabb, aaabbb ...
Strategy: Push A for each 'a'. Pop A for each 'b'. Accept when stack has only Z₀.
Figure P1 — PDA for aⁿbⁿ. Push A on 'a', pop A on 'b'. Final state q2 reached when Z₀ is top (all matched).
P2
L = {aⁿcbⁿ | n ≥ 1}
n a's, separator 'c', n b's: acb, aacbb, aaacbbb ...
Strategy: Push A for each 'a'. On reading 'c', switch state (stack unchanged). Pop A for each 'b'. Accept when Z₀ on top.
Figure P2 — PDA for aⁿcbⁿ. Key: 'c' is the separator — switch q0→q1 on 'c' without touching the stack (c,A/A).
P3
L = {0ᵐ1ⁿ2ⁿ | m, n ≥ 0}
Any 0s, then equal 1s and 2s: ε, 12, 00, 1122, 001122 ...
Strategy: Ignore 0s (no stack change). Push A for each '1'. Pop A for each '2'. Accept when stack has only Z₀.
Figure P3 — PDA for 0ᵐ1ⁿ2ⁿ. q0 skips all 0s. q1 pushes A for each 1. q2 pops A for each 2. Dashed: shortcut for n=0.
P4
L = {aⁿb³ⁿ | n ≥ 1}
n a's followed by 3n b's: abbb, aabbbbbb ...
Strategy: For each 'a' read, push 3 A's using 2 intermediate ε-states (qa, qb). Then pop 1 A per 'b'. Accept when stack has Z₀ only.
Figure P4 — PDA for aⁿb³ⁿ. Each 'a' triggers q0→qa→qb→q0, pushing 3 A's per 'a'. Then b's pop A's one-by-one.
P5
L = {w ∈ {a,b}* | #a(w) = #b(w)}
Strings with equal count of a's and b's: ε, ab, ba, aabb, abba, baba ...
Strategy: Stack tracks excess. If more a's: push A. If more b's: push B. Opposite symbol cancels (pops). Accept when only Z₀ remains.
Figure P5 — PDA for equal a's and b's. Single q0 state handles all cases. Orange arrows = cancellation (pop). Accept when balanced (Z₀ on top).
P6
L = {wwᴿ | w ∈ {a,b}*} — Even Palindromes (NPDA)
Strings equal to their reverse (even length): ε, abba, baab, aabbaa ...
Strategy: PUSH phase — push every symbol. ε-transition guesses middle (NONDETERMINISTIC). MATCH phase — pop and verify mirror. NPDA required — no deterministic way to find midpoint.
Figure P6 — NPDA for palindromes wwᴿ. Pink arrows = nondeterministic ε-guess of midpoint. Both q0→q1 transitions exist simultaneously — NPDA explores all paths.
P7
L = {abⁿacabⁿa | n ≥ 0}
Pattern: a·bⁿ·a·c·a·bⁿ·a. Equal b-runs around 'aca' center. e.g. aaca (n=0), ababcaba... wait: abacaba (n=1)
Strategy: Read 'a', push B for each 'b' in first group, read 'a', read 'c', read 'a', pop B for each 'b' in second group, read final 'a'.
Figure P7 — PDA for abⁿacabⁿa. 6 states tracking each symbol in the pattern. Push B's for first b-run, pop B's for second b-run.
P8
L = {aⁱbʲcᵏ | i, j, k ≥ 0 and i+j = k}
Combined a's and b's count equals c's: ε, c, ac, bc, aabc (1+1=2) ...
Strategy: Push X for every 'a' AND every 'b'. Pop X for every 'c'. Accept when stack empty (X-count = c-count).
Figure P8 — PDA for aⁱbʲcᵏ (i+j=k). Push X for every a and b. Pop X for every c. Stack empty → i+j matched k.
P9
L = {aⁿbᵐcᵐdⁿ | n, m ≥ 0}
Nested two-pair matching: ε, ad, aabbccdd, abcd ...
Strategy: Push A for each 'a'. Then push B for each 'b' (on top of A's). Pop B for each 'c'. Pop A for each 'd'. Stack structure: B's on top, A's below.
Figure P9 — PDA for aⁿbᵐcᵐdⁿ. A's pushed for a's. B's pushed ON TOP for b's. B's popped for c's first. A's popped for d's last. Nested structure.
P10
L = Balanced Parentheses over Σ = {(, )}
Properly nested parentheses: ε, (), (()), ()(), ((())), (()()) ...
Strategy: Push '(' for every '(' read. Pop '(' for every ')' read. Accept when stack has only Z₀ (all parens matched).
Figure P10 — PDA for balanced parentheses. Push '(' on '('. Pop '(' on ')'. Accept when only Z₀ remains (all matched). Orange = pop transition.
