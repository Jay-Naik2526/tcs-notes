4.1 Introduction to Context Free Grammar
4.1.1 Position in Chomsky Hierarchy
Attribute Detail
Grammar Type Type 2 — Context Free Grammar (CFG)
Language Generated Context Free Language (CFL)
Automaton to Accept Pushdown Automaton (PDA)
Production Form A → α — Single non-terminal on LHS, any string on RHS
Why "Context Free"? Non-terminal A can be replaced by α regardless of surrounding symbols — no context needed.
Formal Definition — 4-Tuple

A Context Free Grammar G is a 4-tuple: G = (V, T, P, S)

Symbol Name Description Example
V Variables / Non-Terminals Symbols that can be replaced. LHS of productions. S, A, B
T Terminals Actual language symbols. Cannot be replaced. V ∩ T = ∅ a, b, 0, 1
P Productions / Rules Rules of the form A → α where A ∈ V, α ∈ (V ∪ T)* S → aSb | ε
S Start Symbol The starting non-terminal. S ∈ V S
Critical Constraint — LHS Must Be Single Non-Terminal
  • In CFG, every production has exactly ONE non-terminal on the Left Hand Side.
  • The RHS (α) can be any string of terminals and non-terminals — including ε.
  • This is what distinguishes CFG (Type 2) from CSG (Type 1) where LHS can have context symbols.
  • V ∩ T = ∅ — Variables and Terminals must be disjoint sets.
4.1.2 CFG Examples — Standard Languages

1. CFG for (a + b)*abb — all strings ending with "abb"

S → Aabb
A → aA | bA | ε

2. CFG for abb(a + b)* — all strings starting with "abb"

S → abbA
A → aA | bA | ε

3. CFG for Palindromes over {a, b} — strings w = reverse(w)

S → aSa | bSb | a | b | ε
Palindrome Derivation — "abba"

S ⇒ aSa ⇒ abSba ⇒ abεba ⇒ abba ✓

S ⇒ aSa ⇒ aaSaa ⇒ aaεaa ⇒ aaaa ✓

4. CFG for L = {aⁿbⁿ | n ≥ 1} — equal a's and b's (no ε)

S → aSb | ab
Derivation — "aaabbb" (n=3)

S ⇒ aSb ⇒ aaSbb ⇒ aaabbb ✓

5. CFG for L = {aⁿbⁿ | n ≥ 0} — equal a's and b's (including ε)

S → aSb | ε

6. CFG for L = {aⁿbᵐ | n ≤ m + 3}

S → aaaA | aaA | aA | A
A → aAb | B
B → Bb | ε

7. CFG for L = {aⁿbⁿcᵐdᵐ | n, m ≥ 0} — two independent counters

S → AB
A → aAb | ε     (generates aⁿbⁿ)
B → cBd | ε     (generates cᵐdᵐ)

8. CFG for L = {w ∈ {a,b}* | #a = #b} — equal number of a's and b's

S → aSb | bSa | SS | ε
NOT a CFL — Classic Trap

L = {aⁿbⁿcⁿ | n ≥ 1} is NOT context-free. A CFG cannot handle three-way equal counting. This requires a CSG (Type 1). Use the Pumping Lemma for CFLs to prove it's not a CFL.

4.1.3 Derivations and Derivation Trees
Types of Derivation
  • Leftmost: Always replace the LEFTMOST non-terminal first.
  • Rightmost: Always replace the RIGHTMOST non-terminal first.
  • Both may yield different derivation orders but same tree for unambiguous grammars.
Derivation Tree (Parse Tree)
  • Root = Start symbol S
  • Leaf nodes = Terminals or ε
  • Internal nodes = Non-terminals
  • Children of A = RHS of production used for A
  • Yield (leaves left-to-right) = derived string
Parse Tree — "aab" from S → aS | bS | a | b
      S
     / \
    a   S
       / \
       a   S
           |
           b

Leftmost derivation: S ⇒ aS ⇒ aaS ⇒ aab

4.2 Ambiguous CFG
Definition

A CFG is ambiguous if there exists at least one string in L(G) that has two or more distinct parse trees (equivalently, two or more distinct leftmost derivations).

Classic Ambiguous Grammar — Arithmetic Expressions

Grammar: E → E + E | E * E | id

String: id + id * id

This has two different parse trees:

Parse Tree 1 — (id+id)*id
    E
   /|\
  E * E
 /|\   |
E + E  id
|    |
id   id

Adds first, then multiplies

Parse Tree 2 — id+(id*id)
    E
   /|\
  E + E
  |  /|\
  id E * E
     |   |
    id   id

Multiplies first, then adds ✓ (correct)

Removing Grammar Ambiguity — Unambiguous Equivalent
  • Introduce precedence: * binds tighter than +.
  • Introduce associativity: left-to-right evaluation.

Unambiguous grammar for arithmetic expressions:

E → E + T | T      (+ is lowest precedence, left-associative)
T → T * F | F      (* is higher precedence)
F → id | (E)     (highest precedence — atom)
Inherent Ambiguity

Some languages are inherently ambiguous — every grammar that generates them is ambiguous. Ambiguity cannot be removed for such languages, only for the grammar.

4.3 Grammar Simplification (Reduction)
Definition

Grammar simplification removes unnecessary productions and symbols from a CFG without changing the language L(G). It is a required prerequisite before converting to CNF or GNF.

Three Simplification Steps — Always in this Order
  • Step 1: Remove Useless Symbols (non-terminating + unreachable)
  • Step 2: Remove ε-Productions (A → ε)
  • Step 3: Remove Unit Productions (A → B)
4.3.1 Step 1 — Remove Useless Symbols
What is a Useless Symbol?

A symbol X is useless if it is non-terminating (never leads to a terminal string) OR unreachable (cannot be reached from start symbol S).

1a
Find Non-Terminating Symbols: A non-terminal is terminating if it can derive some string of ONLY terminals. Mark each symbol as terminating or not. Remove those that never terminate.
1b
Find Unreachable Symbols: Starting from S, mark all symbols reachable via productions. Any symbol NOT reachable from S is useless. Remove it.
Problem 4.1 — Remove useless symbols

Given grammar:

S → aA | a | Bb | cC
A → aB
B → a | Aa
C → cCD
D → ddd
1a
Non-terminating check: D → ddd ✓ terminating. C → cCD — contains C (recursive, never resolves to only terminals) ✗ C is non-terminating. B → a ✓. A → aB ✓. S has alternatives without C ✓.
Remove C and all productions containing C: remove S → cC and C → cCD.
1b
Reachability check after removing C: From S: reach A, B. From A: reach B. D is not reachable from S → remove D and D → ddd.

Simplified Grammar:

S → aA | a | Bb
A → aB
B → a | Aa
Problem 4.2 — Remove useless symbols
S → A
A → aA | ε
B → bA
1a
All symbols terminate (A → ε, B → bA, S → A). No non-terminating symbols.
1b
From S: reach A. B is unreachable. Remove B → bA.

Result:

S → A
A → aA | ε

Note: S → A is a unit production. We remove it next (Step 3), resulting in S → aS | ε.

4.3.2 Step 2 — Remove ε-Productions
Definition

An ε-production is any production of the form A → ε. We remove ALL ε-productions, except S → ε if ε ∈ L(G).

1
Find Nullable Symbols: A non-terminal X is nullable if X ⇒* ε (can derive ε).
2
Create New Productions: For each production containing nullable symbols, create all possible combinations with those symbols optionally removed.
3
Remove ε-productions: Delete all A → ε. Add S → ε back ONLY if ε ∈ L(G).
Problem 4.3 — Eliminate ε from:
S → AbB
A → aA | ε
B → bB | aB | ε
1
Nullable: A → ε ✓, B → ε ✓. S? S → AbB — if A=ε, B=ε: S → εbε = b ≠ ε, so S NOT nullable.
2
For S → AbB (A and B nullable): Remove A → S → bB. Remove B → S → Ab. Remove both → S → b.
2
For A → aA (A nullable): Remove right A → A → a.
2
For B → bB (B nullable): Remove B → B → b. For B → aB: Remove B → B → a.
3
Remove A → ε and B → ε. ε ∉ L(G) originally (S not nullable), so no S → ε added.

Result after ε-elimination:

S → AbB | bB | Ab | b
A → aA | a
B → bB | aB | b | a
Problem 4.4 — Eliminate ε from: (harder case with S nullable)
S → ABA
A → aA | ε
B → bB | ε
1
Nullable: A ✓, B ✓. S → ABA: if A=ε, B=ε, S → ε·ε·A → ε (via A→ε). So S is also nullable.
2
For S → ABA (all three nullable), generate all 2³-1 = 7 combinations without ε-form:
S → ABA | BA | AB | AA | A | B (and S→ε which we handle separately)
2
For A → aA: A → a. For B → bB: B → b.
3
Remove A→ε, B→ε. Since ε ∈ L(G), add S → ε.

Result:

S → ABA | BA | AB | AA | A | B | ε
A → aA | a
B → bB | b

Note: S → A and S → B are unit productions — will be removed in Step 3.

4.3.3 Step 3 — Remove Unit Productions
Definition

A unit production is any production of the form A → B where both A and B are non-terminals (single non-terminal on both sides).

1
Find Unit Pairs: (A, B) is a unit pair if A ⇒* B using only unit productions. Compute the transitive closure.
2
Add Non-Unit Productions: For each unit pair (A, B), add all non-unit productions of B to A.
3
Remove All Unit Productions.
Problem 4.5 — Remove unit productions
S → A | bb
A → B | b
B → S | a
1
Unit pairs (transitive closure):
Direct: S→A, A→B, B→S.
S ⇒* A, S ⇒* B, S ⇒* S (cycle: S→A→B→S).
A ⇒* B, A ⇒* S, A ⇒* A. B ⇒* S, B ⇒* A, B ⇒* B.
2
Non-unit: S→bb, A→b, B→a.
S gets from {S,A,B}: S→bb, S→b, S→a.
A gets from {S,A,B}: A→bb, A→b, A→a.
B gets from {S,A,B}: B→bb, B→b, B→a.
3
Remove S→A, A→B, B→S. Check reachability: A and B unreachable from S → remove them.

Final simplified grammar:

S → a | b | bb
Problem 4.6 — Remove unit productions
S → 0A | 1B | C
A → 0S | 00
B → 1 | A
C → 01
1
Unit pairs: S ⇒* C, B ⇒* A.
2
S gets from C: S → 01. B gets from A: B → 0S | 00.
3
Remove S→C, B→A. Check reachability: C is no longer reachable → remove C → 01.

Final grammar:

S → 0A | 1B | 01
A → 0S | 00
B → 1 | 0S | 00
4.3.4 Complete Simplification — Full Worked Example
Problem 4.7 — Apply all 3 simplification steps
S → Ab | aB
A → aA | ε
B → bB | A | b

Step 1 — Useless symbols: All symbols reachable from S. All terminate (A→ε, B→b, S has alternatives). No useless symbols. Skip.

Step 2 — Remove ε: Nullable: A. For S → Ab: remove A → S → b. For B → A: remove A → B → ε... wait, A→ε is what we're removing. B → A: A nullable → B → ε? No — B → A means B can derive whatever A derives. A derives ε, so B is also nullable!

2a
Nullable: A ✓. B → A (A nullable) → B ✓ nullable. S → Ab (A nullable) → S → b, NOT ε (b remains). S → aB (B nullable) → S → a. S is NOT nullable.
2b
For S → Ab: remove A → S → b.
For S → aB: remove B → S → a.
For A → aA: remove A → A → a.
For B → bB: remove B → B → b (already exists).
Remove A → ε and B → ε (B was nullable through A).

After ε-removal:

S → Ab | b | aB | a
A → aA | a
B → bB | A | b

Step 3 — Remove unit productions: Unit production: B → A. Unit pair: B ⇒* A.

3
B gets A's non-unit productions: B → aA | a. Remove B → A.

Final simplified grammar:

S → Ab | b | aB | a
A → aA | a
B → bB | aA | a | b
4.4 Chomsky Normal Form (CNF)
4.4.1 Definition & Algorithm
Chomsky Normal Form — Definition

A CFG is in CNF if every production is of exactly one of these forms:

Form 1: A → BC

Exactly two non-terminals on RHS. Both A, B, C must be non-terminals.

Examples: S → AB, E → CF, X → YZ

Form 2: A → a

Exactly one terminal on RHS. A is a non-terminal, a is a terminal.

Examples: A → a, B → 0, C → b

Special Case for ε

If ε ∈ L(G), then S → ε is allowed, BUT S must NOT appear on the RHS of any production.

CNF Conversion Algorithm — 3 Phases
  • Phase 0 (prerequisite): Fully simplify grammar (remove useless, ε, unit productions).
  • Phase 1: Replace terminals in long RHS (length ≥ 2) with new non-terminals. For each terminal 'a' appearing in a multi-symbol RHS, create Xₐ → a and replace 'a' with Xₐ.
  • Phase 2: Break any RHS with more than 2 symbols. For A → B₁B₂B₃...Bₙ (n > 2), introduce new non-terminals to make it binary: A → B₁C₁, C₁ → B₂C₂, ..., Cₙ₋₂ → Bₙ₋₁Bₙ.
4.4.2 CNF Conversion — Solved Problems
CNF Problem 1 — Simple conversion

1
Already simplified. No ε, no unit, no useless.
P1
In S → cSS: terminal 'c' in multi-symbol RHS. Create C → c. Replace: S → CSS.
P2
S → CSS has 3 symbols. Create D → SS. Replace: S → CD.

Final CNF:

S → CD | a | b
C → c
D → SS

Verify: S→CD (2 NTs ✓), S→a (1 terminal ✓), C→c (1 terminal ✓), D→SS (2 NTs ✓). All CNF.

CNF Problem 2 — Palindromes over {a, b}

4.5 Greibach Normal Form (GNF)
4.5.1 Definition & Algorithm
Greibach Normal Form — Definition

A CFG is in GNF if every production is of the form: A → a α where A is a non-terminal, a is a single terminal, and α is a (possibly empty) string of non-terminals.

Valid GNF Productions
  • A → aBC — terminal then 2 NTs
  • A → a — just a terminal
  • A → aB — terminal then 1 NT
  • A → abcBC — ✗ WRONG — only ONE terminal at start
Why GNF?
  • Every production STARTS with a terminal.
  • Makes grammar analysis easier.
  • Used in PDA construction (each production pops one stack symbol).
  • Every CFL (without ε) has an equivalent GNF grammar.
GNF Conversion Algorithm
  • Step 1: Simplify grammar. Convert to CNF first (or at least simplify).
  • Step 2: Rename non-terminals as A₁, A₂, A₃, ... (A₁ = S).
  • Step 3: Make all productions satisfy: Aᵢ → Aⱼα where j > i, OR Aᵢ → aα. Use substitution to achieve this — if Aᵢ → Aⱼα and j ≤ i, substitute the productions of Aⱼ.
  • Step 4: Eliminate direct left recursion. If Aᵢ → Aᵢα (bad!), use the standard algorithm:
    Convert: A → Aα₁ | Aα₂ | β₁ | β₂ to:
    A → β₁ | β₂ | β₁A' | β₂A' and A' → α₁ | α₂ | α₁A' | α₂A'
  • Step 5: Substitute backwards so all productions start with a terminal.
4.5.2 GNF Conversion — Solved Example
GNF Problem 1 — Convert to GNF
S → AB
A → BS | a
B → SA | b
1
Rename: A₁ = S, A₂ = A, A₃ = B.
A₁ → A₂A₃
A₂ → A₃A₁ | a
A₃ → A₁A₂ | b
2
Check ordering:
A₁ → A₂A₃: j=2 > i=1 ✓
A₂ → A₃A₁: j=3 > i=2 ✓
A₂ → a: terminal ✓
A₃ → A₁A₂: j=1 < i=3 ✗ PROBLEM
A₃ → b: terminal ✓
3
Fix A₃ → A₁A₂: Substitute A₁ (A₁ → A₂A₃): A₃ → A₂A₃A₂ | bA₂ ... wait, also A₃ → b is fine.
Now substitute A₂ in A₃ → A₂A₃A₂ (A₂ → A₃A₁ | a):
A₃ → A₃A₁A₃A₂ | aA₃A₂
Plus original A₃ → b.
A₃ now has LEFT RECURSION (A₃ → A₃A₁A₃A₂).
4
Eliminate left recursion from A₃:
A₃ → A₃(A₁A₃A₂) | aA₃A₂ | b
α = A₁A₃A₂, β₁ = aA₃A₂, β₂ = b
Create new non-terminal Z:
A₃ → aA₃A₂ | b | aA₃A₂Z | bZ
Z → A₁A₃A₂ | A₁A₃A₂Z
5
Substitute to make Z start with terminal:
Z → A₁A₃A₂ — A₁ = A₂A₃ — A₂ → A₃A₁ | a.
Eventually all productions of Z start with 'a' or 'b' (terminal).
6
Back-substitute A₁ and A₂:
A₁ → A₂A₃ — A₂ → A₃A₁ | a → substitute → A₁ → A₃A₁A₃ | aA₃.
Then A₃ → aA₃A₂ | b | ... → substitute → A₁ → aA₃A₂A₁A₃ | bA₁A₃ | aA₃.

Final GNF grammar (all productions start with terminal):

A₁ → aA₃A₂A₁A₃ | bA₁A₃ | aA₃
A₂ → aA₃A₂A₁ | bA₁ | a
A₃ → aA₃A₂ | b | aA₃A₂Z | bZ
Z → aA₃A₂A₁A₃A₂ | bA₁A₃A₂ | ... (all start with terminal)
GNF Problem 2 — Simpler direct substitution
S → bA | aB
A → bAA | aS | a
B → aBB | bS | b

This grammar is already in GNF! Every production starts with a terminal (a or b):

Verification

S → bA: starts with 'b' ✓ | S → aB: starts with 'a' ✓

A → bAA: starts with 'b' ✓ | A → aS: starts with 'a' ✓ | A → a: terminal only ✓

B → aBB: starts with 'a' ✓ | B → bS: starts with 'b' ✓ | B → b: terminal only ✓

All productions are in GNF form A → a α. This grammar is ready.

4.6 Closure Properties of Context Free Languages
Operation Regular Languages Context Free Languages Proof Method
Union — L₁ ∪ L₂ ✓ YES ✓ YES Add new start: S → S₁ | S₂
Concatenation — L₁ · L₂ ✓ YES ✓ YES Add new start: S → S₁S₂
Kleene Star — L* ✓ YES ✓ YES S₁ → SS₁ | ε
Complement — L̄ ✓ YES ✗ NO No general construction works for PDA
Intersection — L₁ ∩ L₂ ✓ YES ✗ NO Counterexample exists (see below)
Difference — L₁ − L₂ ✓ YES ✗ NO L₁ − L₂ = L₁ ∩ L̄₂; since ∩ fails, difference fails
CFL ∩ Regular Language — ✓ YES Special case: intersection of CFL with RL is always CFL
4.6.1 Proof — Union (CFGs)
Proof by Grammar Construction
  • L₁ = L(G₁) with start S₁. L₂ = L(G₂) with start S₂.
  • Create new grammar G with: New start S → S₁ | S₂, plus all productions of G₁ and G₂.
  • L(G) = L₁ ∪ L₂ — S chooses to derive either S₁'s language or S₂'s language.
Example — L₁ = palindromes, L₂ = {aⁿbⁿ}
S → S₁ | S₂
S₁ → aS₁a | bS₁b | a | b | ε
S₂ → aS₂b | ε
4.6.2 Proof — Concatenation (CFGs)
Proof by Grammar Construction
  • New start: S → S₁S₂ (S derives something from L₁ followed by something from L₂).
  • Plus all productions of G₁ and G₂.
4.6.3 Proof — Kleene Star (CFGs)
Proof by Grammar Construction
  • New start S₁: S₁ → SS₁ | ε (zero or more repetitions of L).
  • S is the original start. L* = zero or more strings from L.
4.6.4 NOT Closed — Intersection Counterexample
Counterexample — CFLs NOT Closed Under Intersection

L₁ = {aⁿbⁿcᵐ | n, m ≥ 1} — CFL (grammar: S → AB, A → aAb | ab, B → cB | c)

L₂ = {aᵐbⁿcⁿ | n, m ≥ 1} — CFL (grammar: S → AB, A → aA | a, B → bBc | bc)

L₁ ∩ L₂ = {aⁿbⁿcⁿ | n ≥ 1} — NOT a CFL! (requires counting all three equally — needs Type 1)

Therefore, CFLs are NOT closed under intersection. □

Corollary — NOT Closed Under Complement

If CFLs were closed under complement, then L₁ ∩ L₂ = (L̄₁ ∪ L̄₂) — would be CFL (by De Morgan + union). But we just showed L₁ ∩ L₂ is not a CFL. Contradiction. So CFLs are NOT closed under complement either.

Special Case — CFL ∩ Regular = CFL (Always Closed!)
  • The intersection of a CFL with a Regular Language is always a CFL.
  • Proof: Use product construction of PDA and DFA. The resulting PDA accepts the intersection.
  • Example: {aⁿbⁿ | n ≥ 1} ∩ (a+b)* (regular) = {aⁿbⁿ | n ≥ 1} (still CFL) ✓

(Using S → aSb | ε)
2

Write a CFG for L = {aⁿbᵐ | m > n ≥ 0} — more b's than a's.

Analysis: m = n + k where k ≥ 1. So strings are aⁿbⁿbᵏ (k ≥ 1).
S → AB, A → aAb | ε, B → bB | b
A generates equal a's and b's (including ε). B generates one or more extra b's.
3

Is L = {aⁿbⁿcⁿ | n ≥ 1} a CFL? Justify using the Pumping Lemma for CFLs.

NOT a CFL. By Pumping Lemma for CFLs: w = aⁿbⁿcⁿ, |w| ≥ p. Split w = uvxyz with |vy| ≥ 1, |vxy| ≤ p.
vxy can span at most TWO symbol types (since |vxy| ≤ p). Pumping (i=2) increases only 1 or 2 symbol counts, not all three equally. So uv²xy²z ∉ L. Contradiction. L is NOT a CFL. □
4

Show that grammar G: S → aS | Sa | a is ambiguous. Give two parse trees for "aaa".

Tree 1 (left-first): S ⇒ aS ⇒ a(Sa) ⇒ a(aa) = aaa.
Tree 2 (right-first): S ⇒ Sa ⇒ (aS)a ⇒ (aa)a = aaa.
Two distinct leftmost derivations → grammar is AMBIGUOUS.
Simplification Problems
5

Remove useless symbols from: S → AB | CA, A → a, B → BC | AB, C → aB | b

Step 1a (non-terminating): A → a ✓. C → aB | b ✓ (b terminal). B → BC | AB — B contains B (recursive). Check: B → AB → aB → aBC → ... never terminates! B is NON-TERMINATING.
Remove all productions containing B: remove S → AB, remove B → BC | AB, remove C → aB.
After Step 1a: S → CA, A → a, C → b.
Step 1b (reachability): From S: reach C, A. All remaining symbols reachable.
Final: S → CA, A → a, C → b.
6

Eliminate ε-productions from: S → aSb | A, A → aA | ε

Nullable: A (directly). Does S become nullable? S → A → ε: YES, S is nullable.
New productions: From S → aSb: S not in RHS... wait, a and b are terminals, only S appears. S is nullable but removing S from aSb → aSb still has 'a' and 'b'. No change to S → aSb.
From S → A: A nullable → S → ε (S is nullable, add S → ε since ε ∈ L).
From A → aA: Remove A → A → a.
Remove A → ε. Keep S → ε since ε ∈ L.
Final: S → aSb | A | ε, A → aA | a.
7

Remove unit productions from: S → A | 0B1, A → B | 1, B → S | 0

Unit pairs: S→A, A→B, B→S. Transitive: S⇒*A,B,S; A⇒*B,S,A; B⇒*S,A,B.
Non-unit: S→0B1, A→1, B→0.
S gets from {S,A,B}: S→0B1, S→1, S→0.
A gets from {S,A,B}: A→0B1, A→1, A→0.
B gets from {S,A,B}: B→0B1, B→1, B→0.
Final (after removing unreachables A,B): S → 0B1 | 1 | 0, B → 0B1 | 1 | 0.
CNF & GNF Problems
8

Convert S → aS | a | Sb to CNF.

Simplify: No ε, no unit, no useless.
Phase 1: Create A → a, B → b. S → AS | a | SB.
Phase 2: All productions already have ≤ 2 symbols on RHS.
Final CNF: S → AS | a | SB, A → a, B → b. ✓
9

Convert S → ASA | aB, A → B | S, B → b | ε to CNF. (First simplify!)

Step 1 (ε): B→ε: B nullable. A→B: A nullable? A→B→ε: YES. S? ASA→ε·S·ε: still has S, not nullable.
New: S→ASA|SA|AS|S (unit)|aB|a. A→B|S|ε... wait A→ε: A nullable confirmed. B→b.
After removing A→ε, B→ε: S→ASA|SA|AS|S|aB|a; A→B|S; B→b.
Step 2 (units): S→S trivial (remove), S⇒*A⇒*B. A⇒*B,S. Get non-units into S: S→ASA|SA|AS|aB|a|b. A→b|{S's non-units}→A→ASA|SA|AS|aB|a|b. Remove unit productions.
Step 3 (CNF Phase 1): Create C→a, D→b. S→ASA: replace to S→ASA→ use new NT.
Phase 2: S→ASA (3 syms): S→AE, E→SA. Final CNF: S→AE|SA|AS|CB|a|b, A→AE|SA|AS|CB|a|b, E→SA, C→a, D→b(=B), B→b.
10

Is the grammar S → bA | aB, A → bAA | aS | a, B → aBB | bS | b already in GNF? If yes, verify.

YES, it is in GNF.
S→bA: starts with 'b', followed by NT A ✓. S→aB: starts with 'a', followed by NT B ✓.
A→bAA: starts with 'b', followed by NTs AA ✓. A→aS: starts with 'a', followed by NT S ✓. A→a: single terminal ✓.
B→aBB: starts with 'a', followed by NTs BB ✓. B→bS: starts with 'b', followed by NT S ✓. B→b: single terminal ✓.
All productions: A → a α format. Grammar is in GNF.
Closure Properties
11

Prove that CFLs are closed under reversal (Lᴿ = {wᴿ | w ∈ L}).

Proof by grammar construction: Given CFG G with productions P, construct G' by reversing each production's RHS: if A → X₁X₂...Xₙ ∈ P, add A → Xₙ...X₂X₁ to G'. The start symbol and terminals/non-terminals remain the same. L(G') = L(G)ᴿ. Since G' is a valid CFG, L(G)ᴿ is a CFL. □
12

True or False: The intersection of two CFLs is always a CFL.

FALSE. Counterexample: L₁ = {aⁿbⁿcᵐ | n,m ≥ 1} (CFL) and L₂ = {aᵐbⁿcⁿ | n,m ≥ 1} (CFL). Their intersection = {aⁿbⁿcⁿ | n ≥ 1} which is NOT a CFL (proven by Pumping Lemma). However, the intersection of a CFL with a REGULAR language is always a CFL (special case).
4.8 Quick Revision — Chapter 4
Concept Key Fact
CFG = Type 2 4-tuple (V, T, P, S). LHS = single non-terminal. Generates CFLs. Accepted by PDA.
Context Free A → α regardless of surrounding symbols — no context needed for replacement.
Palindromes S → aSa | bSb | a | b | ε
aⁿbⁿ (n≥1) S → aSb | ab
Ambiguous Grammar At least ONE string has TWO or more parse trees. Arithmetic: E→E+E|E*E|id is classic.
Unambiguous fix E→E+T|T, T→T*F|F, F→id enforces precedence + associativity.
Simplification order 1) Useless symbols (non-terminating then unreachable) 2) ε-productions 3) Unit productions.
Nullable symbol X is nullable if X ⇒* ε. For ε-removal: generate all combos with nullable symbols removed.
Unit production A → B (both non-terminals). Remove by transitive closure: add non-unit productions of B to A.
CNF forms A → BC (exactly 2 NTs) OR A → a (exactly 1 terminal). No mixing, no length > 2.
CNF Algorithm Phase 1: replace terminals in long RHS. Phase 2: break RHS > 2 symbols with new NTs.
GNF form A → a α (single terminal first, then 0+ non-terminals). Every production starts with terminal.
GNF Algorithm Rename NTs, ensure Aᵢ→Aⱼα with j>i, eliminate left recursion, back-substitute.
CFL closed under Union ✓, Concatenation ✓, Kleene Star ✓, Reversal ✓, CFL∩Regular ✓
CFL NOT closed under Complement ✗, Intersection of two CFLs ✗, Difference ✗
NOT a CFL aⁿbⁿcⁿ — equal counting of 3 symbols requires Type 1 (CSG). Classic non-CFL example.
aⁿbⁿcⁿ counterexample Proves CFLs not closed under intersection: {aⁿbⁿcᵐ} ∩ {aᵐbⁿcⁿ} = {aⁿbⁿcⁿ} (not CFL).
Inherently ambiguous Some languages are inherently ambiguous — no unambiguous grammar exists for them.
🎯 Exam Must-Remember
  • CFG LHS = SINGLE non-terminal. If LHS has context (α₁Aα₂), it's CSG (Type 1).
  • Simplification order is CRITICAL: useless → ε → unit. Wrong order gives wrong results.
  • For ε-removal: when all symbols in a RHS are nullable, generate 2ⁿ-1 new productions (all subsets except the ε case itself).
  • For unit removal: transitive closure matters — S→A→B means S⇒*B, so S gets B's productions too.
  • CNF: EVERY production must be A→BC or A→a. Check each one. No terminals in A→BC, no NTs in A→a.
  • GNF: EVERY production must start with EXACTLY ONE terminal, followed by zero or more NTs.
  • CFLs are NOT closed under intersection or complement. Regular sets ARE closed under both.
  • CFL ∩ Regular = CFL (ALWAYS). This special case IS closed.
  • Ambiguity check: find a string with two different leftmost derivations or two different parse trees.
