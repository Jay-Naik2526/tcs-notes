Q1a
Alphabet, String, Language
[5]
Define the following terms with examples: i. Alphabet, ii. String, iii. Language
i. Alphabet (Σ)

An alphabet is a finite, non-empty set of indivisible symbols used to construct strings.
Example: Binary alphabet Σ = {0, 1}, or English alphabet Σ = {a, b, c, ..., z}.

ii. String (Word)

A string is a finite sequence of symbols chosen from an alphabet Σ. The length of a string w, denoted |w|, is the number of symbols it contains.
Example: Over Σ = {0, 1}, w = "0110" is a string of length 4.

iii. Language (L)

A language is a set of strings (which could be finite or infinite) formed over an alphabet Σ. Formally, L ⊆ Σ*.
Example: The language of all binary strings of length 2 over Σ = {0, 1} is L = {"00", "01", "10", "11"}.

Finite Automata Definitions
[5]
What are Finite Automata (FA)? How is FA without output different from FA with output?
Finite Automata (FA)

A Finite Automata is a mathematical model of computation consisting of a finite number of states, transitions, an initial state, and an input alphabet. It reads input symbols one by one and changes its state according to transition rules.

FA without Output vs FA with Output
FA Without Output (DFA / NFA)FA With Output (Moore / Mealy)
Used primarily for Language Recognition (accepting/rejecting strings).Used primarily for Data Transformation (generating an output sequence for an input).
Has a concept of Final/Accepting states.Does not have final or accepting states.
Output is implicit: simply "Yes/Accept" or "No/Reject".Output is explicit: generated at each state or transition.

Q1d
Closure Property: Union of CFGs
[5]
Prove that context-free languages are closed under union operation. L1={aⁿ | n≥1}, L2={bⁿ | n≥1}
Proof using Grammar Construction

To prove CFLs are closed under union, we construct the CFGs for L1 and L2, and show that a new valid CFG can generate L1 ∪ L2.

Grammar for L1 (G1): S1 → aS1 | a Grammar for L2 (G2): S2 → bS2 | b Union Grammar (G_union): Introduce a new start symbol S that branches to either S1 or S2. S → S1 | S2 S1 → aS1 | a S2 → bS2 | b

Since the union of two Context-Free Grammars produces another valid Context-Free Grammar, CFLs are closed under union.

Q2b
Recursive vs REL & TM Power
[10]
Write a short note on: i. Recursive and REL, ii. Power of TM over PDA
Recursive vs Recursively Enumerable Language (REL)

Recursively Enumerable Language (REL): A language is REL if there exists a Turing Machine that will halt and accept any valid string in the language. However, if a string is NOT in the language, the TM might loop forever. (Also known as Turing-recognizable).

Recursive Language: A language is Recursive if there exists a Turing Machine that will always halt—it accepts valid strings and explicitly rejects invalid strings without ever going into an infinite loop. (Also known as Turing-decidable).

Power of TM over PDA

While a PDA has an infinite stack, it can only access the top element (LIFO). A Turing Machine has an infinite read/write tape and a head that can move both left and right freely. This allows the TM to arbitrarily scan, seek, and overwrite data anywhere in memory, enabling it to compute anything that is mathematically computable (like aⁿbⁿcⁿ), which a PDA cannot do.

Q4b
Turing Machine for Reverse of a String
[10]
Design a Turing Machine to find the reverse of a string over Σ={0,1}
TM Logic (Copy in Reverse Strategy)

Given input w (e.g., 01#), the TM will create a reversed copy after a `#` delimiter resulting in 01#10.
1. q0: Scan right to find last unmarked symbol before `#`. Mark it (e.g., `X` or `Y`). Remember it via state (`q1_0` or `q1_1`).
2. q1_0 / q1_1: Scan right past `#` and past any already copied bits until a Blank (`B`) is found.
3. Write the remembered bit, transition to q2, and scan left all the way back to the marks (`X` or `Y`).
4. Step right to the next unmarked bit and repeat until all original bits are marked. Once `#` is reached in `q0`, halt.

Q5b
Grammar Simplification
[10]
What is grammar simplification? Simplify: S→ASB|ε, A→aAS|a, B→SbS|A|bb
Grammar Simplification

Simplification removes unnecessary rules to make the grammar cleaner and parsing more efficient. It involves three steps in order: Removing ε-productions, Removing Unit productions, and Removing Useless symbols.

Step 1: Remove ε-Productions
S is nullable. S → ASB | AB A → aAS | aA | a B → SbS | bS | Sb | b | A | bb
Step 2: Remove Unit Productions
Only unit production is B → A. Replace B → A with A's productions. S → ASB | AB A → aAS | aA | a B → SbS | bS | Sb | b | bb | aAS | aA | a
Step 3: Remove Useless Symbols

All symbols are reachable from S and all symbols generate terminals. Thus, no useless symbols exist. The result from Step 2 is the fully simplified grammar.

PDA Acceptability & Derivation Tree
[10]
What is PDA? Acceptability ways? Derive "aabbaa" for S→aAS|a, A→SbA|SS|ba using RMD.
Push Down Automata (PDA)

A PDA is essentially a Finite State Machine integrated with an external infinite Stack memory (Last-In-First-Out). It is used to recognize Context-Free Languages.

  • Acceptance by Final State: The input is fully consumed and the PDA transitions into an explicitly defined accepting state (stack content doesn't matter).
  • Acceptance by Empty Stack: The input is fully consumed and the stack is completely popped empty (including the initial Z0 symbol). No explicit final state is needed.

Q7
Regular Closure, Type-2 Grammar, Moore, TM Adder
[20]
a. Closure properties of Regular Languages

Regular languages are closed under the following operations. This means if L1 and L2 are regular languages, applying these mathematical operations will produce another valid regular language.

  • Union (L1 ∪ L2): Closed. The language containing strings that are in L1, L2, or both.
  • Intersection (L1 ∩ L2): Closed. The language containing strings strictly in both L1 and L2.
  • Concatenation (L1L2): Closed. Strings formed by appending a string in L2 to a string in L1.
  • Kleene Star (L1*): Closed. Zero or more concatenations of strings from L1.
  • Complement (L1'): Closed. All strings over Σ that are NOT in L1.
b. Syntax for Type-2 Grammar (CFG)

According to the Chomsky Hierarchy, Type-2 Grammars are Context-Free Grammars (CFG). They generate Context-Free Languages which are accepted by Pushdown Automata.

Strict Type-2 Syntax Rule: A → α
  • A must be exactly one Non-Terminal symbol (A ∈ V). Context is irrelevant, hence "context-free".
  • α can be any combination of Terminals and Non-Terminals, including ε (α ∈ (V∪T)*).
