1. What is a DFA?

Definition

A Deterministic Finite Automaton (DFA) is a mathematical model for recognising patterns in strings. It processes an input string one symbol at a time and decides whether to accept or reject it.

A DFA is formally defined as a 5-tuple:

M = ( Q , Σ , δ , q0 , F )
SymbolNameDescription
QSet of StatesFinite, non-empty set of all states the machine can be in
ΣInput AlphabetFinite set of valid input symbols (e.g. {a, b} or {0, 1})
δTransition Functionδ : Q × Σ → Q — given a state and symbol, returns exactly ONE next state
q0Start StateThe state where processing begins; q0 ∈ Q
FAccept StatesSet of states that indicate acceptance; F ⊆ Q
⚠ Key Property — Determinism
  • For every (state, symbol) pair, there is exactly one transition — never zero, never two.
  • No ambiguity. The next state is always completely determined.
  • No ε (epsilon) moves — every step consumes one input symbol.
  • If a transition is unspecified, a hidden dead/trap state is assumed (all input leads to reject).

How it works — step by step

  1. Start in state q0.
  2. Read the first symbol of the input string.
  3. Use δ(current state, symbol) to move to the next state.
  4. Repeat steps 2–3 for every remaining symbol.
  5. After the last symbol — if the current state ∈ F → ACCEPT, else → REJECT.

Accepting a string

A DFA M accepts string w if and only if δ*(q0, w) ∈ F, where δ* is the extended transition function defined as:

δ*(q, ε) = q
δ*(q, xa) = δ(δ*(q, x), a)

The language of DFA M is L(M) = { w ∈ Σ* | δ*(q0, w) ∈ F }

3. Example 2 — Even number of 0s

Language

L = { w ∈ {0,1}* | w contains an even number of 0s }

Note: 0 is even. So ε (empty string) is accepted.

5-Tuple:   Q = {q0, q1}   Σ = {0,1}   q0 = q0   F = {q0}

Intuition: q0 = even count of 0s seen, q1 = odd count of 0s seen.

💡 Design Pattern — Parity Tracking
  • Use 2 states to track even/odd of a single symbol.
  • q0 = even (start & accept), q1 = odd.
  • Generalise: for counting mod k → need k states.
  • Other symbols that don't affect the count → self-loops in both states.

4. Example 3 — Binary strings divisible by 3

Language

L = { w ∈ {0,1}* | integer value of w is divisible by 3 }

e.g. "0" (0), "11" (3), "110" (6), "1001" (9) ∈ L

Key Insight: Track the remainder when dividing by 3 (mod 3).

If current value = n and we read bit b:

new value = 2n + b   →   new remainder = (2 × old_remainder + b) mod 3

5-Tuple:   Q = {q0, q1, q2}   Σ = {0,1}   q0 = q0   F = {q0}

⚠ Equivalence Theorem
  • Every NFA can be converted to an equivalent DFA using the Subset Construction algorithm.
  • An NFA with n states may produce a DFA with up to 2n states (worst case).
  • In practice, many states are unreachable — the actual DFA is often much smaller.

6. DFA Minimisation

Multiple DFAs can recognise the same language. The minimum DFA has the fewest possible states. We find it using the Table-Filling Algorithm (Myhill-Nerode).

Table-Filling Algorithm — Steps

  1. Mark all pairs (p, q) where one is an accept state and the other is not — these are distinguishable.
  2. Repeat until no new pairs are marked:
      For each unmarked pair (p, q) and each symbol a:
        If (δ(p,a), δ(q,a)) is already marked → mark (p, q).
  3. Merge all remaining unmarked pairs — they are equivalent (indistinguishable) states.
  4. Build the new minimised DFA using the merged equivalence classes.

Properties of Minimum DFA

PropertyDescription
UniqueUp to isomorphism — only one minimum DFA exists for any regular language
No dead statesIf all transitions are defined (complete DFA), one dead state may remain
No equivalent statesNo two distinct states accept exactly the same set of future strings
No unreachable statesRemove any state unreachable from q0 before minimising

📚 Quick Revision — Must Remember
  • DFA = 5-tuple (Q, Σ, δ, q0, F) — exactly one transition per (state, symbol) pair.
  • Accept if final state ∈ F after reading entire input. Reject otherwise.
  • Double circle in diagram = accept state. Arrow with "start" = start state.
  • DFA ≡ NFA in power. NFA → DFA via subset construction (2n worst case).
  • DFA recognises exactly the Regular Languages.
  • Minimise DFA using Table-Filling (Myhill-Nerode) algorithm.
  • Pumping Lemma proves a language is NOT regular.
